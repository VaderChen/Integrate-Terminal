# Integrate Terminal 1.26.1003 (Build 2336)

適用於 macOS 13 以上、Apple Silicon（arm64）。

## 效率與記憶體

本版在維持既有操作、功能與 UI 的前提下，改善終端輸出、檔案操作、傳輸佇列與 MCP 的處理效率及記憶體使用。

- 終端串流與回放緩衝減少重複配置及複製；事件訂閱跟隨分頁生命週期重用，本機回顯合併寫入，保留原有輸出順序與控制字元行為。
- 大量傳輸使用 ID 索引查找及移除，降低佇列增長時的處理成本；清空後釋放索引與節點參照，保留取消、暫停、父子傳輸及排序規則。
- 批次刪除、檔案多選與拖曳共用路徑解析結果；站台排序預先計算排序鍵，避免逐項重複計算。
- MCP VFS 減少目錄快照及分塊寫入的中間複製；保留檔案容量、SHA-256、路徑與並行操作驗證。
- Telnet、遠端路徑檢查、更新檔選擇與版本資訊讀取減少中間配置。
- 傳輸與日誌 ID 共用遞增時間戳，避免高頻建立或系統時鐘回退造成 ID 重複。

固定資料基準中，新增 10,000 筆傳輸並取得快照由 58.49 ms 降至 1.50 ms，累計配置量約減少 50%；完成 8 MiB RAM 分塊檔案的累計配置量約減少一半。比較基準已包含前一輪高頻路徑最佳化，數據代表特定受測函式，不代表整個 App 的常駐記憶體、GUI 或實際網路吞吐量。完整方法與結果見[函式級最佳化紀錄](https://github.com/VaderChen/Integrate-Terminal/blob/v1.26.1003.2336/doc/function-optimization.md)。

## 日誌保存上限

- 操作日誌保留最近 **1,000 筆**，滿載後淘汰最舊紀錄。
- 崩潰與 REST 錯誤日誌 `service-crash.log` 上限 **5 MiB**；既有超大日誌於下次追加時套用上限。超限時清除舊內容；單筆超限時保留尾端 5 MiB。
- macOS 更新安裝日誌僅保留最近一次安裝的內容。

## 驗證與安裝

已通過 Go race、go vet、54 項前端行為測試、TypeScript 型別檢查，以及封裝、更新、沙盒與原生橋接 Smoke。原生 GUI 人工操作及外部真實伺服器連線未納入本輪驗證。

App 與 DMG 已完成 Developer ID 簽章、Apple 公證、票根及 Gatekeeper 驗證；掛載後亦已核對版本、架構、雜湊，並通過包內 MCP 的 RAM 檔案及分塊寫入 Smoke。

下載 DMG，將 IntegTERM 拖入 Applications。可使用附件 `SHA256SUMS.txt` 校驗下載檔案；既有使用者亦可從「關於」頁面檢查更新。
