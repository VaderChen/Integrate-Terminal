# IntegTERM 1.26.0929（Build 1305）測試版

發布標籤：`v1.26.0929.1305`。平台：macOS 13 以上、Apple Silicon（arm64）。

## 本次變更

- 恢復站台編輯雙欄版面，讓主機／連接埠、帳號／密碼、PPK／密語與本機／遠端路徑成對排列；窄視窗可捲動。
- 補回協定左側的標籤欄位，支援逗號分隔、去重、清空、JSON 儲存與重新開啟。
- PPK 依檔案加密標記決定是否需要密語；未加密金鑰可留空，缺少私鑰不再誤報缺少密語。
- 改善 PPK 完整性驗證失敗提示，不顯示原始 HMAC 雜湊；仍保留所有驗證。
- 提供本機 PPK 診斷工具，可直接驗證指定檔案，避免混淆執行版本、保存副本或站台／分頁設定。
- 延續本分支的 Go 1.27.1、專案 Wails CLI、JSON 檔案儲存與 MCP 即時說明泡泡。

## 驗證

- `scripts/test.sh` 通過：Go 全套測試與 race detector、go vet、封裝與沙盒測試、Swift 模擬測試、40 項前端測試及 TypeScript 檢查。
- 前端正式建置、Wails macOS arm64 建置與 App ad-hoc 簽章驗證通過。
- PPK v2／v3 載入、錯誤密語、損毀檔案、未加密 SSH 握手 Smoke，以及上游獨立樣本驗證通過。
- 使用者回報的實際 PPK 連線問題尚未完成驗證；本版不宣稱已修復該個案。

## 相容性與使用方式

此版本為 Pre-release，保留 9/12 版本作為 Latest。本分支與 9/12 正式版功能集合不同，尚未包含該版的收藏站台、資料夾授權與強制更新介面。資料模型不保留未知 JSON 欄位；測試前請備份站台、分頁與設定檔。

App 直接讀取指定的 PPK 路徑，不讀取舊版保存的金鑰副本或查詢系統憑證儲存。更新站台後，請從已儲存站台建立新連線測試，既有分頁仍保存自己的連線設定。

PPK 診斷 ZIP 解壓後，雙擊 `check-ppk.command`，貼上 PPK 絕對路徑並輸入密語。密語隱藏輸入，只透過標準輸入傳遞，不寫入參數、環境變數或檔案，也不連線遠端站台。ZIP 內附 arm64 執行檔，不需要 Go。回報診斷結果即可，不需提供密語或私鑰內容。

App 與診斷工具使用 ad-hoc 簽章，未經 Apple 公證。此 Release 不會自動安裝或取代目前執行中的 App。下載附件可使用 `SHA256SUMS.txt` 比對完整性。
