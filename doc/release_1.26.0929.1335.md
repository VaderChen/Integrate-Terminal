# Integrate Terminal 1.26.0929 (Build 1335)

For macOS 13 or later on Apple Silicon (arm64).

## Improvements

- Updated the macOS distribution package.
- Includes the two-column site editor, file-based tags, and clearer PPK validation messages from Build 1305.

## Installation

Download the DMG, open it, and drag IntegTERM to Applications.

## Compatibility

This branch differs from the September 12 release and does not yet include favorite sites, folder authorization, or forced updates. Back up saved sites, tabs, and settings before upgrading. PPK files are read directly from their configured paths. The reported PPK connection issue still requires diagnosis with the affected file.
