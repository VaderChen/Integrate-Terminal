# Integrate Terminal 1.26.1004 (Build 0046)

適用於 macOS 13 以上、Apple Silicon（arm64）。

## 選單列多螢幕顯示修正

- 修正不同螢幕或縮放倍率下，選單列圖示旁的 `ACT／背景連線數` 被截斷。
- 選單列現在依圖示及雙行文字的完整尺寸預留空間，連線數增加或減少時會自動調整寬度；繪製解析度由目前的顯示 context 決定。
- 保留原有圖示、字型、雙行排列、深淺色樣式、提示文字與點擊選單操作。
- 延續上一版的效率與記憶體最佳化，以及操作日誌 1,000 筆、崩潰日誌 5 MiB 的保存上限。

## 驗證與安裝

原生 AppKit Smoke 已涵蓋 6 種連線數、3 種選單列高度、1×／1.5×／2× 交替繪製及標題切換；同一份回歸測試能在修改前版本重現寬度不足，修改後通過。完整 Go race、go vet、54 項前端測試、TypeScript 檢查及既有 Smoke 亦通過。實體多螢幕切換尚未進行人工驗證。

App 與 DMG 已完成 Developer ID 簽章、Apple 公證、票根及 Gatekeeper 驗證；掛載後已核對版本、arm64 架構、檔案雜湊與新版托盤實作，並通過包內 MCP 啟動與 RAM 檔案操作 Smoke。

下載 DMG，將 IntegTERM 拖入 Applications；亦可從「關於」頁面檢查更新。附件 `SHA256SUMS.txt` 可用於校驗下載檔案。套用更新後，請重新啟動 IntegTERM 與背景服務，使選單列載入新版。
